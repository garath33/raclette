# Raclette Point Original

Prezentační web sítě Raclette Point. Dokumentace je ve složce [docs](docs/README.md).

Ostrý web se z téhle větve nenasazuje. Postup je v [docs/pipeline.md](docs/pipeline.md).

```bash
npm ci
npm test
npm start
```
